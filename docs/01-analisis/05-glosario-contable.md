# Glosario contable

> Versión 0.1 · 17-oct-2026 · Definiciones de apoyo para quien lea el proyecto. Están redactadas a partir de conocimiento general y de las fuentes citadas en `03` y `06`. ⚠️ Deben ser revisadas por el autor contra la norma.

## Tributario

| Término | Definición |
|---|---|
| **DIAN** | Dirección de Impuestos y Aduanas Nacionales de Colombia. |
| **UVT** | Unidad de Valor Tributario. Unidad de medida en pesos que se actualiza cada año y con la que se expresan topes, sanciones y límites. UVT 2025: $49.799; UVT 2026: $52.374 ✅ (ver `03`). |
| **Año gravable** | Año al que corresponden los ingresos que se declaran (por ejemplo, 2025). |
| **Año de presentación** | Año en que se presenta la declaración (por ejemplo, 2026). |
| **Declarante** | Persona obligada a presentar declaración de renta. |
| **Topes (para declarar)** | Montos de ingresos, patrimonio, consumos, compras o consignaciones que, al superarse, obligan a declarar. |
| **Patrimonio bruto** | Total de bienes y derechos a 31 de diciembre, sin restar deudas. |
| **Patrimonio líquido** | Patrimonio bruto menos las deudas. |
| **Ingresos brutos** | Total de ingresos del año antes de restar costos o deducciones. |
| **Renta líquida** | Resultado después de restar costos, deducciones y rentas exentas, según corresponda. |
| **Cédulas de renta** | Categorías en que se agrupan los ingresos de una persona natural: rentas de trabajo, de pensiones, de capital, no laborales y otros ✅ (Rankia). |
| **Formulario 210** | Formulario de la declaración de renta de personas naturales residentes. |
| **Deducción** | Gasto que la norma permite restar de la base del impuesto. |
| **Renta exenta** | Ingreso que la norma deja total o parcialmente sin gravar. |
| **Retención en la fuente** | Anticipo del impuesto que descuenta quien paga, y que el beneficiario puede imputar después. |
| **RUT** | Registro Único Tributario. |
| **Firma electrónica (IFE)** | Instrumento de la DIAN para firmar y presentar declaraciones y reportes de forma virtual ✅ (INCP). |
| **Información exógena** | Reporte anual que ciertas personas y entidades hacen a la DIAN sobre sus operaciones con terceros. También se conoce como "medios magnéticos". |
| **Formato (exógena)** | Estructura definida por la DIAN para cada tipo de información reportada; cambia por año gravable. |
| **Tercero** | Persona o entidad con la que el cliente tiene una operación (proveedor, cliente, empleado, banco). |
| **GMF (4x1000)** | Gravamen a los Movimientos Financieros: impuesto de 4 por mil sobre ciertas transacciones financieras. |
| **Exención del GMF** | Monto mensual de retiros que no paga GMF si se cumplen las condiciones (350 UVT por mes ✅, ver `06`). |
| **Cuenta marcada** | Cuenta que el titular designa ante el banco para aplicar la exención del GMF. ⚠️ Su exigencia genera discrepancias entre fuentes (ver `06`). |

## Laboral y nómina

| Término | Definición |
|---|---|
| **SMMLV** | Salario Mínimo Mensual Legal Vigente. 2026: $1.750.905 ✅ (Decreto 1469 de 2025). |
| **Auxilio de transporte** | Pago adicional para trabajadores que ganan hasta cierto tope de salarios mínimos. 2026: $249.095 ✅ (Decreto 1470 de 2025). |
| **Empleador / trabajador** | Quien contrata y quien presta el servicio bajo subordinación. |
| **IBC** | Ingreso Base de Cotización: valor sobre el que se calculan los aportes a seguridad social. |
| **Aportes a seguridad social** | Aportes a salud (EPS), pensión (fondo de pensiones) y riesgos laborales (ARL). |
| **Aportes parafiscales** | Aportes a caja de compensación, SENA e ICBF. |
| **Prestaciones sociales** | Prima de servicios, cesantías e intereses a las cesantías. A ellas se suman las vacaciones. |
| **Provisión** | Valor que se reserva mes a mes para pagar una obligación futura (por ejemplo, la prima). |
| **Liquidación de nómina** | Cálculo del salario, deducciones, aportes y neto a pagar de un período. |

## Contabilidad general

| Término | Definición |
|---|---|
| **PUC** | Plan Único de Cuentas: catálogo de cuentas contables. |
| **Partida doble** | Principio de que cada operación afecta al menos dos cuentas y el total de débitos es igual al de créditos. |
| **Comprobante** | Documento interno que registra una operación contable. |
| **Soporte** | Documento externo que respalda una operación (factura, recibo, certificado). |
| **Conciliación bancaria** | Comparación entre el extracto del banco y los registros propios para detectar diferencias. |

## Términos del sistema

| Término | Definición |
|---|---|
| **Parámetro** | Valor (UVT, tope, porcentaje, fecha) guardado con vigencia, fuente y estado. |
| **Vigencia** | Rango de fechas en que un parámetro aplica. |
| **Expediente** | Conjunto de información, movimientos y soportes de un cliente. |
| **Papel de trabajo** | Documento de apoyo que prepara el contador; no es la declaración oficial. |
| **Semáforo** | Indicador de avance (verde, amarillo, rojo) de un cliente frente a un tope. |
| **Nivel de verificación** | ✅ verificado · ⚠️ probable · ❓ no verificado. |
